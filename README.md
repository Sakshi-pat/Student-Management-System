📚 Student Management System (Spring Boot)

A complete Student Management System (SMS) built using Spring Boot, demonstrating full CRUD operations (Create, Read, Update, Delete).
This project is ideal for learning Spring Boot, REST APIs, JSON handling, and connecting Spring Boot applications with databases.

🚀 Features
✔️ Add Student (Create)

Create a new student record

Implemented using POST request

Endpoint: /api/students

✔️ Get Students (Read)

Fetch all students

Fetch single student by ID

Implemented using GET

Endpoints:

/api/students

/api/students/{id}

✔️ Update Student (Update)

Update existing student information

Implemented using PUT

Endpoint: /api/students/{id}

✔️ Delete Student (Delete)

Remove student by ID

Implemented using DELETE

Endpoint: /api/students/{id}

🛠️ Tech Stack

Java 17+

Spring Boot

Spring Web

Spring Data JPA

MySQL / H2 Database

Maven

Lombok (optional)
